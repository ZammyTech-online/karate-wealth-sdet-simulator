# Pistas de L00

Pista 1 está en cada ejercicio. Aquí tienes la pista 2. La pista 3 es la solución: `academia solucion L00 E0X`.

## E01 · El método para leer

Los métodos son get, post, put, patch y delete. Para leer sin cambiar nada se usa get.

## E02 · Predice el código de éxito

200 significa OK. 201 es para cuando se crea algo nuevo, y aquí solo leemos.

## E03 · Pide un fondo concreto

El primer fondo del catálogo tiene el ISIN SE0000000001. Un ISIN tiene 12 caracteres.

## E04 · Predice el código de algo que no existe

Los errores del cliente empiezan por 4. 'No encontrado' es el 404.

## E05 · Predice el código de una petición mal hecha

404 es 'existe el formato pero no el recurso'. 400 es 'lo que pides no tiene sentido'.
