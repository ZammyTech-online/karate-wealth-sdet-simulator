# complaints-service

Reclamaciones de clientes con plazos legales en días hábiles (acuse en 2, respuesta en 15), caso en case-management, resolución y vencidas.

| Dato | Valor |
| --- | --- |
| Dominio | E-compliance |
| Equipo dueño | Cumplimiento |
| Puerto | 6407 |
| Oleada | 4 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | case-management, customer-registry, permission-service, clock-service |
| Publica eventos | `complaint.received`, `complaint.resolved` |
| Consume eventos | — |
| Swagger | http://localhost:6407/swagger |
| Colección Bruno | `collections/cumplimiento` |
