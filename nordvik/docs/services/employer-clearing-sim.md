# employer-clearing-sim

E9 Clearing de Empleadores: ficheros CSV mensuales de aportaciones, webhook firmado con HMAC hacia Nordvik y acuses de aceptadas y rechazadas.

| Dato | Valor |
| --- | --- |
| Dominio | X-external |
| Equipo dueño | Sistema externo (simulado) |
| Puerto | 7709 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | clock-service |
| Publica eventos | — |
| Consume eventos | — |
| Swagger | http://localhost:7709/swagger |
| Colección Bruno | `collections/sistema-externo-simulado` |
