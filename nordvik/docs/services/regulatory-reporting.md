# regulatory-reporting

Informes al supervisor: operaciones ejecutadas por día (T+1, seudonimizadas, agregadas por ISIN) e incidentes de datos por mes; marca los envíos tardíos.

| Dato | Valor |
| --- | --- |
| Dominio | E-compliance |
| Equipo dueño | Cumplimiento |
| Puerto | 6408 |
| Oleada | 4 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | order-management, breach-service, clock-service |
| Publica eventos | `regulatory-report.submitted` |
| Consume eventos | — |
| Swagger | http://localhost:6408/swagger |
| Colección Bruno | `collections/cumplimiento` |
