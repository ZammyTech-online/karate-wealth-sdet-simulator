# kyc-aml-service

Casos KYC: cribado + PEP + riesgo en orden, aprobación automática según riesgo, revisión de Cumplimiento con cuatro ojos y fecha de próxima revisión.

| Dato | Valor |
| --- | --- |
| Dominio | E-compliance |
| Equipo dueño | Cumplimiento normativo |
| Puerto | 6400 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | sanctions-adapter, pep-service, risk-scoring, customer-registry, clock-service |
| Publica eventos | `kyc.approved`, `kyc.rejected`, `kyc.review-required` |
| Consume eventos | — |
| Swagger | http://localhost:6400/swagger |
| Colección Bruno | `collections/cumplimiento-normativo` |
