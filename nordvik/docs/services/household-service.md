# household-service

Unidad familiar: cónyuge o pareja, hijos y dependientes, con reglas de coherencia (una sola pareja, hijos nacidos después que el cliente) y números nacionales tokenizados.

| Dato | Valor |
| --- | --- |
| Dominio | D-customer |
| Equipo dueño | Cliente |
| Puerto | 6306 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | customer-registry, pii-vault, permission-service, clock-service |
| Publica eventos | `household.updated` |
| Consume eventos | — |
| Swagger | http://localhost:6306/swagger |
| Colección Bruno | `collections/cliente` |
