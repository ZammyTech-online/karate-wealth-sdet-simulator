# meeting-scheduler

Agenda del asesor: huecos de 60 min en su horario y días hábiles, reservas sin solapes, cancelación tardía (<24 h) y recordatorios 24 h antes por notification-service.

| Dato | Valor |
| --- | --- |
| Dominio | G-advice |
| Equipo dueño | Asesoramiento y comunicación |
| Puerto | 6604 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | advisor-directory, permission-service, customer-registry, notification-service, clock-service |
| Publica eventos | `meeting.booked`, `meeting.cancelled` |
| Consume eventos | — |
| Swagger | http://localhost:6604/swagger |
| Colección Bruno | `collections/asesoramiento-y-comunicacion` |
