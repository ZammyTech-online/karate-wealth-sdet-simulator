# pep-service

Estado PEP/RCA del cliente: autodeclaración + cribado de la lista PEP, con detección de declaraciones que no cuadran.

| Dato | Valor |
| --- | --- |
| Dominio | E-compliance |
| Equipo dueño | Cumplimiento normativo |
| Puerto | 6402 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | sanctions-adapter, customer-registry, permission-service, clock-service |
| Publica eventos | `pep.identified` |
| Consume eventos | — |
| Swagger | http://localhost:6402/swagger |
| Colección Bruno | `collections/cumplimiento-normativo` |
