# token-exchange

Intercambio de tokens (RFC 8693): token del usuario → token de menos permisos para un servicio concreto, más corto y sin poder ampliar scopes.

| Dato | Valor |
| --- | --- |
| Dominio | C-identity |
| Equipo dueño | Identidad |
| Puerto | 6206 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | clock-service |
| Publica eventos | `token.exchanged` |
| Consume eventos | — |
| Swagger | http://localhost:6206/swagger |
| Colección Bruno | `collections/identidad` |
