# suitability-service

Test de idoneidad MiFID II: cuestionario → perfil de riesgo 1-7, y comprobación fondo a fondo (SRI, horizonte, sostenibilidad). Caduca a los 2 años.

| Dato | Valor |
| --- | --- |
| Dominio | E-compliance |
| Equipo dueño | Cumplimiento normativo |
| Puerto | 6405 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | customer-registry, permission-service, clock-service |
| Publica eventos | `suitability.assessed`, `suitability.checked` |
| Consume eventos | — |
| Swagger | http://localhost:6405/swagger |
| Colección Bruno | `collections/cumplimiento-normativo` |
