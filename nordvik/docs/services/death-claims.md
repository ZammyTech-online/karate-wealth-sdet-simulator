# death-claims

Reclamaciones por fallecimiento: congelación de planes, suspensión de cobros, verificación, reparto por beneficiarios (o ESTATE) y liquidación.

| Dato | Valor |
| --- | --- |
| Dominio | L-pensions |
| Equipo dueño | Pensiones |
| Puerto | 7113 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | pension-plan-service, payout-planner, beneficiary-service, valuation-service, customer-registry, insurance-policy, clock-service |
| Publica eventos | `death-claim.opened`, `death-claim.verified`, `death-claim.settled` |
| Consume eventos | — |
| Swagger | http://localhost:7113/swagger |
| Colección Bruno | `collections/pensiones` |
