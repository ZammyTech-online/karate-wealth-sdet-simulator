# insurance-policy

Pólizas de vida e invalidez ligadas al plan de pensión: declaración de salud vigente, prima con recargo, emisión en la aseguradora y cancelación.

| Dato | Valor |
| --- | --- |
| Dominio | M-insurance |
| Equipo dueño | Seguros |
| Puerto | 7200 |
| Oleada | 4 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | pension-plan-service, health-declaration, premium-calculator, insurer-adapter, customer-registry, permission-service, clock-service |
| Publica eventos | `insurance-policy.issued`, `insurance-policy.status-changed` |
| Consume eventos | — |
| Swagger | http://localhost:7200/swagger |
| Colección Bruno | `collections/seguros` |
