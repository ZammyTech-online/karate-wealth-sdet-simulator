# population-adapter

Consulta al Registro de Población (E2) con mTLS simulado: identidad protegida sin dirección, fallecidos (evento) y comparación con la ficha del cliente.

| Dato | Valor |
| --- | --- |
| Dominio | P-integrations |
| Equipo dueño | Integraciones |
| Puerto | 7503 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | population-sim, secrets-service, pii-vault, customer-registry, clock-service |
| Publica eventos | `population.deceased-detected` |
| Consume eventos | — |
| Swagger | http://localhost:7503/swagger |
| Colección Bruno | `collections/integraciones` |
