# breach-service

Brechas de datos: plazo de 72 h para avisar a la autoridad, aviso a los afectados si el riesgo es alto, marcas de retraso y cierre.

| Dato | Valor |
| --- | --- |
| Dominio | F-privacy |
| Equipo dueño | Privacidad |
| Puerto | 6509 |
| Oleada | 4 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | notification-service, customer-registry, clock-service |
| Publica eventos | `breach.reported`, `breach.authority-notified`, `breach.closed` |
| Consume eventos | — |
| Swagger | http://localhost:6509/swagger |
| Colección Bruno | `collections/privacidad` |
