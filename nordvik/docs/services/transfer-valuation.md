# transfer-valuation

Valoración previa de pólizas externas para traspasos: asíncrona (1–3 días virtuales), validez de 30 días y comparación con tolerancia del 2 %.

| Dato | Valor |
| --- | --- |
| Dominio | L-pensions |
| Equipo dueño | Pensiones |
| Puerto | 7109 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | provider-network-adapter, customer-registry, permission-service, clock-service |
| Publica eventos | `transfer-valuation.ready` |
| Consume eventos | — |
| Swagger | http://localhost:7109/swagger |
| Colección Bruno | `collections/pensiones` |
