# tax-reporting

Informe fiscal anual en lote: pagos de pensión del año por cliente, fichero de control a la Agencia Tributaria con acuse; original y correcciones.

| Dato | Valor |
| --- | --- |
| Dominio | N-tax |
| Equipo dueño | Fiscalidad |
| Puerto | 7301 |
| Oleada | 4 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | payout-execution, customer-registry, tax-agency-adapter, clock-service |
| Publica eventos | `tax-report.filed` |
| Consume eventos | — |
| Swagger | http://localhost:7301/swagger |
| Colección Bruno | `collections/fiscalidad` |
