# mock-control

Panel único de los sistemas externos simulados: estado, comportamiento (normal, down, error, slow, failNext) y reinicio de todos a la vez.

| Dato | Valor |
| --- | --- |
| Dominio | Q-quality |
| Equipo dueño | Calidad y test |
| Puerto | 7601 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | — |
| Publica eventos | — |
| Consume eventos | — |
| Swagger | http://localhost:7601/swagger |
| Colección Bruno | `collections/calidad-y-test` |
