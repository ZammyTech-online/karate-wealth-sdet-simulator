# chaos-control

Inyecta latencia y errores en cualquier servicio (faults con probabilidad, veces y caducidad) y gestiona el catálogo de trampas T1-T20.

| Dato | Valor |
| --- | --- |
| Dominio | Q-quality |
| Equipo dueño | Calidad y test |
| Puerto | 7600 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | — |
| Publica eventos | — |
| Consume eventos | — |
| Swagger | http://localhost:7600/swagger |
| Colección Bruno | `collections/calidad-y-test` |
