# task-queue

Tareas humanas por rol: crear, reclamar, completar o soltar; vencimiento con el reloj virtual y quién hizo cada cosa.

| Dato | Valor |
| --- | --- |
| Dominio | O-operations |
| Equipo dueño | Operaciones y back office |

| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | clock-service |
| Publica eventos | `task.created`, `task.completed` |
| Consume eventos | — |
| Swagger | http://localhost:7404/swagger |
