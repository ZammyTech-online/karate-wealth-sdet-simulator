# transfer-service

Traspasos entrantes desde otras gestoras: saga con valoración, confirmación del cliente, aprobación de Operaciones, tolerancia del 2 %, revisión manual e historial.

| Dato | Valor |
| --- | --- |
| Dominio | L-pensions |
| Equipo dueño | Pensiones |
| Puerto | 7108 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | transfer-valuation, provider-network-adapter, pension-plan-service, contribution-service, permission-service, clock-service |
| Publica eventos | `transfer.requested`, `transfer.status-changed`, `transfer.completed` |
| Consume eventos | — |
| Swagger | http://localhost:7108/swagger |
| Colección Bruno | `collections/pensiones` |
