# transaction-monitoring

Alertas por patrones: estructuración, transferencias grandes, entrada y salida rápida, países de riesgo. Ventanas sobre el reloj virtual.

| Dato | Valor |
| --- | --- |
| Dominio | E-compliance |
| Equipo dueño | Cumplimiento normativo |
| Puerto | 6404 |
| Oleada | 3 |
| Versión | 1.0.0 |
| Convención JSON | CamelCase |
| Depende de | event-bus, clock-service |
| Publica eventos | `monitoring.alert.raised`, `monitoring.alert.closed` |
| Consume eventos | `deposit.received`, `payment.settled` |
| Swagger | http://localhost:6404/swagger |
| Colección Bruno | `collections/cumplimiento-normativo` |
